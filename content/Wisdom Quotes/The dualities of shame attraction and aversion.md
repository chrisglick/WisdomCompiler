**THE DUALITIES OF SHAME**

| Attraction | Aversion |
|---|---|
| Self-punitive | Self-forgiveness |
| Depression | Choose life |
| Judgmental | Surrender to God’s Mercy |
| Negativity | Let go of position |
| Shrink, hide | Be visible |
| Self as worthless | Affirm gift of life |
| Rigid self-view | Correctable, flexible |
| Condemn | Forgive |
| Mortification | Choose self-worth |
| Denigrate | Honor self |
| Self-hatred | Self-forgiveness |
| Severe | Benign |
| Imbalanced | See both sides |
