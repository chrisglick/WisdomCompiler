## Key Technical Details

### Quartz Component Architecture
Components are Preact functional components receiving `QuartzComponentProps` (includes `fileData`, `cfg`, `allFiles`, `displayClass`). They can have:
- `css` — static CSS string (component-scoped)
- `beforeDOMLoaded` — JS that runs before DOM ready
- `afterDOMLoaded` — JS that runs after DOM ready (compiled into `postscript.js`)

For SPA compatibility, `afterDOMLoaded` scripts must use `document.addEventListener("nav", callback)` — this fires on initial load AND on every SPA navigation.

### ConditionalRender Pattern
```typescript
Component.ConditionalRender({
  component: Component.RandomQuote(),
  condition: (page) => page.fileData.slug === "index",
})
```
The `condition` function receives the page data at build time. Returns `true` to render, `false` to skip.

### Quote Generation Pipeline
```
python scripts/generate-quotes.py
  ├─ Scans content/Screenshots/Notes/*.md
  ├─ Filters: Edited: true, non-UUID filename, readable title
  ├─ Extracts: title (quote text), source (frontmatter), slug (path)
  ├─ Quality filters: min 25 chars, max 150, no fragments, no chapter numbers
  └─ Outputs: quartz/components/scripts/randomquote.inline.ts
```

### CSS Variables Used
- `--light` — page background
- `--lightgray` — border/subtle background
- `--darkgray` — body text
- `--gray` — muted text (citations)
- `$mobile` — Quartz breakpoint variable: `(max-width: 800px)`
