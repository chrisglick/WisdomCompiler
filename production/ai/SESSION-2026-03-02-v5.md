## What Was Done

### 1. Explorer Crash Fix (quartz.layout.ts)

- **Bug:** Explorer sidebar showed heading "Explorer" but no content. Console error: `TypeError: Cannot read properties of undefined (reading 'toLowerCase')`
- **Root cause:** `node.name.toLowerCase()` in the custom `filterFn` — some tree nodes (root/virtual) have `undefined` for `.name`
- **Fix:** Added optional chaining and null guard in BOTH `defaultContentPageLayout` and `defaultListPageLayout`:
  ```typescript
  filterFn: (node) => {
    const name = node.name?.toLowerCase()
    if (!name) return true
    const excluded = ["tags", "screenshots", "social-media", "lakshmi the cow", "about"]
    return !excluded.includes(name)
  },
  ```
- **Commit:** `12bec71 fix(explorer): guard filterFn against undefined node names`
- **Pushed:** to `origin/v4`

### 4. Browser Skill Diagnosis

- **Problem:** `bun run Browse.ts <url>` fails with "Failed to start browser session" from within Claude Code
- **Investigation:**
  - Playwright v1.57.0 installed, chromium binaries present (revision 1200, 1208)
  - Tested: bundled Chromium headless, bundled Chromium with 30s timeout, system Edge via `channel: 'msedge'`
  - Browser process LAUNCHES successfully but Playwright cannot establish `--remote-debugging-pipe` IPC connection
- **Root cause:** Claude Code sandbox blocks pipe-based inter-process communication between Bun and the spawned browser process
- **NOT a code bug** — platform limitation of the Claude Code sandbox environment
- **Workaround:** Run Browser skill from an external terminal (outside Claude Code) where there's no sandbox restriction

## Key Technical Details

### Explorer filterFn Node Structure
Quartz Explorer tree nodes have a `.name` property for visible folders/files, but root and virtual nodes can have `undefined`. Always use optional chaining (`node.name?.toLowerCase()`) when filtering.

### Cloudflare Pages Deploy

### Playwright Sandbox Limitation
- Playwright uses `--remote-debugging-pipe` flag to communicate with the browser via stdio pipes
- Claude Code's sandbox restricts this IPC mechanism
- The browser process spawns and is visible in Task Manager but the control channel never connects
- All browser variants (Chromium bundled, system Edge, headless/headed) fail identically
