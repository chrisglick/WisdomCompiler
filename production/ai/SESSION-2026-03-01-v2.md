### 2. Image Path Fix (fix-image-paths.py)
- **Problem:** Quartz CrawlLinks "shortest" strategy only resolves markdown files in `allSlugs`, not binary assets. Image wikilinks `![[IMG.png]]` broke.
- **Root cause:** `transformLink` fallback computes `pathToRoot(src) + canonicalSlug`. From `/Screenshots/Notes/page`, `pathToRoot` = `../../`. So the canonicalSlug must contain the full content-root path.
- **Solution:** Convert all image embeds to `![](Screenshots/Images/filename)` so fallback produces `../../Screenshots/Images/filename` — correct from any depth.
- First attempt (`../Images/`) failed — CrawlLinks mangles relative paths.
- Script: `scripts/fix-image-paths.py` (now subsumed by lint-screenshots.py)

### 3. Screenshot Notes Lint Pipeline (lint-screenshots.py)
Created `scripts/lint-screenshots.py` — the main cleaning pipeline with 4 passes:

1. **Remove `text::` prefix** — dataview inline field marker removed from all 648 notes. Also catches `test::` typo.
2. **Add `ShowImage` frontmatter** — ALL notes get `ShowImage: true` (37 Meme notes) or `ShowImage: false` (611 others). Human can flip any note to `true` to restore its image.
3. **Remove image embed** — `![](Screenshots/Images/...)` line removed unless `ShowImage: true`. The `image_name` field in frontmatter preserves the reference.
4. **Paragraph formatting** — For notes >500 chars, OCR double-space markers (`"  "`) converted to `\n\n` paragraph breaks. 375 notes formatted.

Script is idempotent — second run modifies 0 files.

## Decisions Made
1. **Full content-root paths for images** — Not relative paths. Quartz fallback needs full path.
2. **ShowImage opt-in** — Default false. Human adds `true` for visual content.
3. **Edited filter on book pages** — Only reviewed notes appear. Prevents OCR garbage on the live site.
4. **Double-space = paragraph break** — OCR consistently uses `"  "` as paragraph gap marker. No library needed.
5. **>500 char threshold** — Short quotes (227 notes) left as single paragraphs. Longer texts (421 notes) get formatting.
