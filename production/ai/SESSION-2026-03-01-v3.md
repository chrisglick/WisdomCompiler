## Key Technical Details

### Explorer FilterFn Pattern
The `filterFn` receives `FileTrieNode` objects. Filter by `node.name` (case-insensitive) against an exclusion list. Must be applied to BOTH explorer instances (content page layout + list page layout) in `quartz.layout.ts`.

### Script Architecture (generate-book-links.py)
```
scan_screenshots() → groups by source
    ↓
For each book:
  ├─ Has passages → rewrite_page() preserving link section + set draft: false
  └─ No passages → preserve link section + write placeholder + set draft: true

extract_link_section() → parses only ## header + "- [" link lines
set_frontmatter_draft() → regex replace on draft: true/false
```

### Quartz Folder Pages
When `FolderPage()` is an emitter (it is in config), Quartz auto-generates index pages for folders listing all non-draft children. Linking to `[[Books/]]` uses this auto-generated page — no need for a manual `Books.md` index.

### Theme Default Behavior
- First visit (no localStorage): shows light mode
- User toggles: preference saved to localStorage, persists across visits
- System preference changes: still listened to via `change` event on `prefers-color-scheme` media query
