# New Book Template

> Copy this template to `content/Books/{Book Title}.md` and fill in the fields.

## Frontmatter

```yaml
---
sticker: emoji//1f4d6
Author: Author Name
title: Book Title
source: https://link-to-free-online-text
tags:
draft: false
---
```

### Field Reference

| Field | Required | Description |
|-------|----------|-------------|
| `sticker` | Yes | Always `emoji//1f4d6` (book emoji) |
| `Author` | Yes | Author's name (matches a Teacher page if one exists) |
| `title` | Yes | Exact book title — this becomes the page title and wiki-link target |
| `source` | Yes | URL to a free online version, or `url` as placeholder if none found yet |
| `tags` | No | Optional tags (leave empty or omit) |
| `draft` | Yes | Set `false` to publish, `true` to hide from site |

## Page Structure

```markdown
## Read Online
- [Book Title — description (host)](https://link-to-full-text)

## Passages

- [[Quote filename 1]]
- [[Quote filename 2]]
```

### Section Notes

- **Read Online** — Link to a free, legal full-text source. Prefer: Archive.org, publisher PDFs, official sites (e.g., sriramanamaharshi.org). Format: `[Title — translator/edition (host)](url)`
- **Passages** — Wiki-links to quote notes in `content/Wisdom Quotes/`. These are auto-generated by `scripts/generate-book-links.py` based on each quote's `source` frontmatter field. You can also add them manually.

## How Passage Links Work

1. Each quote in `content/Wisdom Quotes/` has a `source` field like `source: "[[Book Title]]"`
2. Running `python scripts/generate-book-links.py` scans all quotes and rebuilds the `## Passages` section on each book page
3. Manual additions are preserved if placed above the auto-generated block

## Checklist

- [ ] Filename matches the book title exactly (used for wiki-link resolution)
- [ ] `Author` field matches the teacher name (creates backlink if Teacher page exists)
- [ ] `source` URL is a free, legal full-text link
- [ ] `draft: false` when ready to publish
- [ ] At least one quote has `source: "[[Book Title]]"` linking back to this page
